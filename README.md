# Magnet_order — свод по торговым точкам

Локальный инструмент в браузере: из **ZIP-вложения письма Magnit** (заказ + выгрузка монтажей) собирает **одну строку на ТТ**.

## Зачем ZIP

В файле заказа адрес часто обрезан (`Москва г`, `Краснодарский край, Краснодар г`). В том же письме лежит выгрузка **«Эдтех Солюшн монтажи …xlsx»** с полным адресом, форматом ММ, площадью и датами. Инструмент склеивает источники:

| Источник | Что берём |
|----------|-----------|
| `Заказ*.xlsx` | ТТ, RCC, типы монтажа, количества, даты поставки/монтажа |
| `Эдтех Солюшн монтажи*.xlsx` | адрес (только если в заказе неполный), формат ММ, площадь, даты |
| `*.pdf` | игнорируется |

В одном ZIP может быть несколько заказов — все позиции объединяются.

## Как пользоваться

1. Откройте `index.html` (нужен интернет для SheetJS + JSZip).
2. Выберите **ZIP** из письма (или отдельные `.xlsx`).
3. Укажите номер **очереди**.
4. Нажмите **«Сгенерировать результат»** → CSV / Excel / TSV.

После правок кода: `npm run build`.

## Выход

Без изменений по колонкам: одна строка на ТТ (очередь, область, адрес, формат, даты, количества монтажей, медиаплеер, площадь).

- «Дата открытия из заказа» всегда пустая.
- «Дата открытия» = максимум среди дат заказа и выгрузки монтажей.
- Адрес и область преимущественно из заказа. Если улица в заказе неполная — дозаполняется из монтажей, но **область остаётся из заказа**.
