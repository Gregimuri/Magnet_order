# Magnet_order — свод по торговым точкам

Локальный инструмент в браузере: из выгрузки заказов на монтаж (Эдтех / Магнит) собирает **одну строку на каждую ТТ** с количествами работ в отдельных колонках.

Исходники: `app.js`, `transform.js`. Для страницы нужен собранный бандл `svod.iife.js` (уже лежит в репозитории).

## Как запустить

1. Откройте `index.html` в браузере (двойной клик или любой локальный сервер).
2. Для чтения/записи Excel нужен интернет (CDN SheetJS).
3. После правок кода пересоберите бандл:

```bash
npm run build
```

или

```bash
npx esbuild app.js --bundle --format=iife --platform=browser --outfile=svod.iife.js
```

## Как пользоваться

1. Вставьте таблицу из Excel (Ctrl+V) **или** выберите файл `.xlsx` / `.xls` / `.xlsm`.
2. Укажите номер **очереди** (попадёт в каждую строку результата).
3. Нажмите **«Сгенерировать результат»**.
4. Проверьте предупреждения (если есть) и скачайте **CSV** / **Excel** или скопируйте **TSV**.

## Входной формат

Типичная выгрузка из письма/вложения, например «Эдтех Солюшн монтажи … .xlsx». Берётся **первый лист**. Строки — позиции заказа: у одной ТТ обычно несколько строк (по видам работ).

Ожидаемые колонки (по позиции, с нуля):

| Индекс | Колонка в выгрузке | Назначение |
|--------|--------------------|------------|
| 0 | ТТ | Название торговой точки |
| 1 | Заказ | Номер RCC |
| 2 | ИП | План / служебное (не в свод) |
| 3 | Модель | Тип работ / позиция |
| 4 | Количество | Кол-во |
| 5 | Адрес | Адрес ТТ |
| 6 | Площадь ТТ | Площадь |
| 7–8 | Инженер, телефон | Не в свод |
| 9 | Дата монтажа | Учитывается при выборе даты открытия |
| 10 | Дата открытия | Учитывается при выборе даты открытия |
| … | … | Промежуточные поля выгрузки |
| последняя непустая | Формат | Попадает в «Формат ММ» |

Пример строк входа (упрощённо):

| ТТ | Заказ | Модель | Количество | Адрес | Площадь ТТ | … | Формат |
|----|-------|--------|------------|-------|------------|---|--------|
| Салки | RCC-… | Первичный монтаж дисплея покупателя | 2 | … | 699 | … | БО Новый концепт 3.1 |
| Салки | RCC-… | Первичный монтаж прайсчекера | 1 | … | 699 | … | БО Новый концепт 3.1 |

## Выходной формат

Одна строка на ТТ. Порядок ТТ — как первое появление во входе.

| Колонка | Откуда |
|---------|--------|
| Название ТТ | колонка «ТТ» |
| Очередь | значение из поля «Очередь» на странице |
| Область | выводится из адреса (регион/город по правилам парсера) |
| Адрес | первый встретившийся адрес по этой ТТ |
| Формат ММ | последняя непустая ячейка строки выгрузки (обычно «Формат») |
| термит | пусто (заполняется вручную при необходимости) |
| Усилитель со встроенным плеером | пусто |
| Дата открытия из заказа | всегда пусто |
| Дата открытия | максимальная из распознанных дат монтажа/открытия по строкам ТТ (`ДД.ММ.ГГГГ`) |
| Первичный монтаж дисплея покупателя | сумма количеств |
| Первичный монтаж прайсчекера | сумма количеств |
| Первичный монтаж громкоговорителя | сумма количеств |
| Первичный монтаж системы аудиовещания | сумма количеств |
| Первичный монтаж ТВ панели | сумма количеств |
| Медиаплеер | сумма «Медиаплеер»; если есть монтаж системы аудиовещания — не меньше её количества |
| площадь | среднее по строкам ТТ, округление до целого |

Пример фрагмента результата (как в `svod_tt.xlsx`):

| Название ТТ | Очередь | Адрес | Формат ММ | Дата открытия | … дисплей | … прайсчекер | … громкоговоритель | … аудио | … ТВ | Медиаплеер | площадь |
|-------------|---------|-------|-----------|---------------|-----------|--------------|--------------------|---------|-------|------------|---------|
| Салки | 100 | … | БО Новый концепт 3.1 | 11.12.2026 | 2 | 1 | 7 | 1 | 2 | 1 | 699 |
| Дендробиум | 100 | … | БО Новый концепт 3.1 | 17.12.2026 | 3 | 1 | 4 | 1 | 0 | 1 | 290 |

В результат **не** попадают столбцы «Заказ» и служебные поля инженера; pivot строится только по монтажным типам выше.

## Правила и предупреждения

- Неизвестные типы в «Модель» дают предупреждение; расходники, автотранспорт, доп. выезды, часть оборудования и т.п. игнорируются тихо (без строки в своде по этой позиции).
- Несколько разных RCC / адресов / форматов / площадей у одной ТТ — предупреждение в интерфейсе (строка ТТ подсвечивается).
- Даты Excel-serial и пустые даты во входе обрабатываются парсером; в колонку «Дата открытия из заказа» ничего не пишется намеренно.
