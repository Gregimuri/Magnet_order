# Magnet_order — свод по торговым точкам

Локальный инструмент в браузере: из **файла заказа Magnit** (`Заказ*.xlsx`) собирает **одну строку на каждую ТТ** с количествами монтажных работ в отдельных колонках.

Исходники: `app.js`, `transform.js`. Для страницы нужен собранный бандл `svod.iife.js` (уже в репозитории).

## Как запустить

1. Откройте `index.html` в браузере.
2. Для Excel нужен интернет (CDN SheetJS).
3. После правок кода:

```bash
npm run build
```

## Как пользоваться

1. Выберите файл заказа `.xlsx` (или вставьте таблицу).
2. Укажите номер **очереди**.
3. Нажмите **«Сгенерировать результат»**.
4. Скачайте CSV / Excel или скопируйте TSV.

Формат входа определяется автоматически (заказ Magnit или старая плоская выгрузка).

## Входной формат — заказ Magnit

Типичное вложение из письма, например `Заказ1.xlsx`. Берётся **первый лист**. В шапке — реквизиты и список RCC; ниже таблица позиций.

Структура позиций (после разворота merged-ячеек):

| Колонка | Содержание |
|---------|------------|
| № п/п | номер строки |
| Номер заказа | `RCC-…` |
| Наименование | обычно «Первичный монтаж ИТ-оборудования» |
| Модель | тип работ (громкоговоритель, прайсчекер, …) |
| Кол-во, шт | количество |
| Дата поставки / Дата окончания монтажа | даты |
| Место поставки | **название ТТ** (иногда с `, КПП …` — суффикс отбрасывается) |

У каждой позиции **вторая строка** — адрес в колонке «Место поставки» / «Адрес поставки».

Повторяющиеся заголовки таблицы и блок «Итого» игнорируются. Полей «Формат ММ» и «площадь» в заказе нет — в своде эти колонки остаются пустыми.

## Выходной формат

Без изменений: одна строка на ТТ, порядок — как первое появление во входе.

| Колонка | Откуда |
|---------|--------|
| Название ТТ | «Место поставки» без КПП |
| Очередь | поле на странице |
| Область | из адреса |
| Адрес | адрес со второй строки позиции |
| Формат ММ | пусто (в заказе нет) |
| термит / Усилитель… | пусто |
| Дата открытия из заказа | всегда пусто |
| Дата открытия | max(дата поставки, дата окончания монтажа) |
| колонки монтажей | сумма количеств по типу «Модель» |
| Медиаплеер | явное кол-во; если есть монтаж системы аудиовещания — не меньше его |
| площадь | пусто (в заказе нет) |

Пример (фрагмент):

| Название ТТ | Очередь | Область | Дата открытия | …громкоговоритель | …аудио | …ТВ | Медиаплеер |
|-------------|---------|---------|---------------|-------------------|--------|-----|------------|
| Роскошь | 100 | Краснодарский край | 08.12.2026 | 3 | 1 | 1 | 1 |
| Салки | 100 | Москва | 08.12.2026 | 7 | 1 | 2 | 1 |

## Правила

- В свод попадают только известные типы монтажа; прочее — предупреждение или тихий пропуск.
- Несколько RCC / разные адреса у одной ТТ — предупреждение, строка подсвечивается.
- Старая плоская выгрузка («ТТ / Заказ / Модель / …») по-прежнему поддерживается как запасной формат.
